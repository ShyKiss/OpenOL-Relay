TUI/GUI - Relay между клиентами [OpenOL](https://github.com/ShyKiss/OpenOL) — модифицированного клиента игры Outlast.

Relay — это UDP-сервер игры OpenOL. Он решает, что происходит с общим миром (двери, триггеры, чекпоинты), проверяет сообщения игроков и рассылает результат всем в комнате. Движок игры в нём не запускается: ИИ врагов работает у одного из игроков или в отдельном симуляторе без окна, а выбирает владельца relay.

Как собрать — в [docs/BUILD.md](./docs/BUILD.md). Как запустить в контейнере — в [docs/HOSTING.md](./docs/HOSTING.md).

## Возможности

- **UDP-сервер** на 128 клиентов и до 64 комнат
- **Шифрование трафика** и ключ сервера, который клиенты запоминают, чтобы никто не мог выдать себя за сервер
- **Комнаты** с паролем или без. Пароли не передаются по сети, а хранятся только их хэши
- **Баны** — глобальные и по конкретной комнате, с указанием причины
- **Синхронизация мира** для подключившихся позже: состояния игроков, дверей, врагов и подбираемых предметов
- **Приоритеты игрока с дверью** — пока один игрок взаимодействует с дверью, остальные получают отказ (`DOOR_DENY`)
- **Хранение настроек** в `relay.db` (JSON) рядом с исполняемым файлом
- **Два вида интерфейса**: TUI (консоль с прокручиваемым логом и строкой ввода) и GUI на ImGui
- **Ограничение частоты пакетов** и автоматический таймаут неактивных клиентов

## Конфигурация

Все настройки хранятся в файле `relay.db` (формат JSON), который создаётся рядом с исполняемым файлом. Там же лежат комнаты, хэши паролей и баны:

```json
{
  "config": {
    "name": "OLServer",
    "ip": "0.0.0.0",
    "port": "7777"
  },
  "rooms": [
    {
      "code": "PUBLIC",
      "password": "",
      "trusted": [],
      "bans": []
    }
  ],
  "bans": []
}
```

Файл перезаписывается при изменении настроек через команды/GUI и при завершении работы сервера. Список `trusted` больше не используется.

Ключ сервера хранится отдельно в `relay.db.key`. Этот файл нельзя терять: см. [docs/HOSTING.md](./docs/HOSTING.md).

## Команды

Доступны и в TUI, и в поле ввода на вкладке **Log** в GUI.

| Команда | Описание |
| --- | --- |
| `list` | Список игроков по комнатам |
| `rooms` | Список активных комнат |
| `kick <id>` | Кикнуть игрока |
| `ban <id> [reason]` | Глобальный бан по IP игрока |
| `ban room <code> <id> [reason]` | Бан игрока в конкретной комнате |
| `unban <ip>` | Снять глобальный бан |
| `unban room <code> <ip>` | Снять бан в комнате |
| `bans` | Список всех банов |
| `room create <code> [password]` | Создать комнату |
| `setpw <code> <password>` | Сменить пароль комнаты |
| `stats` | Ключ сервера, трафик, отказы во входе и соединение каждого игрока |
| `log on\|off` | Включить или выключить лог пакетов |
| `quit` | Остановить сервер |
